# Nursing Home Staffing Dashboard

A Streamlit application for analyzing nursing home staffing data from the Payroll-Based Journal (PBJ) system.

## Features
- Facility-level staffing analysis
- State and regional comparisons
- Historical trends visualization
- Citation tracking
- Custom reporting

## Setup
1. Install requirements:
```bash
pip install -r requirements.txt
```

2. Run the application:
```bash
streamlit run pbjbeta.py
```

## Data Sources
- PBJ Daily Nurse Staffing Data
- Nursing Home Provider Information
- Health Citations Data
