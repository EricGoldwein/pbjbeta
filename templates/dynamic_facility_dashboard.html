Methodology & Definitions
Staff Categories
  • Total Staff: All nursing staff including RNs, LPNs, CNAs, administrators, and DON
  • Direct Staff: Staff providing direct patient care (excludes administrators and DON)
  • Total RN (Registered Nurse): Includes RNs + RN administrators + RN DON (Director of Nursing)
  • Direct RN: Excludes RN Admin, RN DON.
  • LPN (Licensed Practical Nurse): Includes direct care LPNs + LPN administrators
  • Nurse Aides: Includes CNAs + NA trainees + Medication Aides
  • Contract Staff: Temporary/agency staff (marked with "_ctr" suffix)
Calculations
  • HPRD (Hours Per Resident Day): Total hours ÷ Census
  • Contract %: (Contract hours ÷ Total hours) × 100
  • Averages: Weighted by census when applicable
  • Rounding: Financial rounding (ROUND_HALF_UP) for all displayed metrics
  • % Case-Mix HPRD: Reported ÷ CMS Case-Mix. Values below 1.0 indicate staffing deficit relative to CMS benchmark expectations; values above 1.0 indicate surplus staffing. Case-mix is a CMS benchmark for staffing based on resident acuity.
  • Non-Direct Staff HPRD: RN Admin/DON & LPN Admin hours per resident day
Harrington Expected Staffing (CMI-Adjusted)

The Harrington Expected formulas adjust expected staffing based on Case-Mix Index (CMI) to account for resident acuity:

  • Total Expected HPRD: 3.48 + ((CMI - 0.62) / (3.84 - 0.62))0.715 × (7.68 - 3.48)
  • RN Expected HPRD: 0.55 + ((CMI - 0.62) / (3.84 - 0.62))0.974 × (2.39 - 0.55)
  • Nurse Aide Expected HPRD: 2.45 + ((CMI - 0.62) / (3.84 - 0.62))0.236 × (3.6 - 2.45)

See: Nursing Home Guide to Adjusting Nurse Staffing for Resident Case-Mix (Harrington)

Note: Direct Care metrics are calculated from PBJ and exclude Admin/DON.

This Nursing Home Staffing Dashboard uses CMS Payroll-Based Journal (PBJ) data from 2017 to 2025, covering all nursing positions, including contract staff (PBJ daily nurse staffing). CMS first published PBJ data in 2017. It also uses Provider Information datasets from 2018 to 2025 (4pq5-n9py).{% if cms_pbj_facility_url %} View raw CMS PBJ data for this facility.{% endif %}

Unlike PBJ data, which is released quarterly, provider info files are published on a rolling monthly basis without a clear reference quarter. To align them with PBJ datasets, we matched the "reported total staffing" metric, which is available in both sources, to the corresponding quarter. This approach is not exact—health inspection data, for example, is updated on a different schedule—but it offers a reasonable best-guess for quarter assignment.{% if provider_info_download_available %} Download CMS Provider File (raw CSV).{% endif %}

Provider file download (Quick links above) and clickable source filenames in the Red Flag History table appear when raw CMS provider CSVs are present in provider_info_extracted or static/data/provider_info next to the app.
